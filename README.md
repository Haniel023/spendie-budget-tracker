# 💜 Spendie

A modern mobile-first budget tracking app built with React, Vite, and Supabase.

Spendie helps users:
- track expenses and income
- create budgets
- manage savings goals
- share spaces with partners/family
- receive smart financial insights
- monitor recurring transactions

---

# ✨ Features

## 💰 Budget Tracking
- Add income and expenses
- Categorize transactions
- Real-time balance updates

## 🎯 Savings Goals
- Create personal savings goals
- Progress tracking
- Goal completion monitoring

## 🧠 Smart Insights
- Spending analysis
- Budget alerts
- Financial recommendations

## 👥 Shared Spaces
- Personal and shared budget spaces
- Invite members
- Collaborative finance tracking

## 🔔 Notifications
- Budget exceeded alerts
- Real-time updates
- Auto-expiring notifications

## 📊 Analytics
- Expense breakdown
- Income vs expenses
- Monthly trends
- Top spending categories

## 📱 Mobile First
- Optimized for iPhone and Android
- PWA support
- Installable app experience
